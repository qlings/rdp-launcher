# 需求规格（v3 / v0.7.0 对照）

> v3 在 v2 基础上补：关 Windows 的 RDP 安全警告、关闭后保持后台（托盘）、
> 托盘右键快速连主机、设置单页且分组编辑放最下面、右下角版本号/关于。
> v0.3.3 做四个输入/显示微调；v0.4.0 做一次全量审计修复（34 项，见下文）；
> v0.4.1 支持空密码登录；v0.4.2 重做托盘行为；v0.4.3 连接成功后不再自动最小化；
> v0.4.4 Esc 不再最小化窗口；v0.4.5 编辑界面可以「复制一份」主机；
> v0.5.0 导入本机远程桌面历史、空列表提示导入、新默认值、关于页 GitHub / 最新版；
> v0.5.1 性能审计（启动路径去阻塞、注册表写挪后台、列表按需重排）；
> **v0.6.0 托盘只列最近 3 台、导入前多选、探活定时刷新 + 按需重测、再一轮速度/可用性优化**；
> **v0.7.0 配置导出/导入（含密码）、在线汇总胶囊缩小、主题挪进设置、关于文案精简**。

### v3 的已知边界

1. 关闭 Windows 安全警告需要管理员授权一次；不带管理员的普通用户无法改 HKLM。
2. 旧版发布者提示的 HKCU 覆盖会关闭服务器证书校验，只适合信任的内网。
3. 托盘图标可能被 Windows 收进 `∧` 溢出区，需要手动拖出/固定。
4. 开发机是断开的 RDP 会话，没法实点托盘图标；已验证：最小化后 `update` 继续、
   `ITaskbarList` DeleteTab/AddTab 返回成功、事件队列能触发 `show_main`。
   真实鼠标点击/DoubleClick 需要在正常桌面会话里确认。

### 探活设计（v0.6.0）

| 点 | 以前 | 现在 |
|---|---|---|
| 频率 | 只在启动第 2 帧测一次，之后永远是那个结论 | 启动测一轮；之后每 30 秒 / 1 分钟 / 5 分钟自动刷新（设置里可关）；`F5` 或点顶部胶囊立刻重测 |
| 重复地址 | 复制出来的副本各连一次 | 同一「地址 + 端口」只连一次，结果扇出给所有同地址主机 |
| 编辑主机 | 地址没变也把整批结果清空重测 | 只重测改过地址/端口的那台；新增主机只测新的；删除主机只丢它自己的状态 |
| 刷新观感 | —— | 旧结果先留着，新结果回来再覆盖，圆点不会整排变灰 |
| 托盘隐藏 | 照常探活 | 不刷新（看不见圆点，省电省网络），还原后按间隔补一轮 |
| 并发 | 一批 32 线程，一批没跑完不能再来 | 允许多批并行（改地址和定时刷新互不阻塞），单批仍 32 线程 / 800ms 超时 / 2.5s 截止 |
| 失败兜底 | 超时把全部主机补成离线 | 只补这一批没回音的主机，已有结果不动 |

### v0.6.0 的已知边界

1. 探活只代表「TCP 端口通的」，不代表账号密码对；离线主机仍可点「连接」尝试。
2. 隐藏到托盘时不做定时刷新，还原后最长要等一个刷新间隔才更新（可以按 `F5` 立刻测）。
3. 托盘图标真实右键菜单的开发机限制见 v3 已知边界 4；菜单内容由单元测试覆盖（只列 3 台 / 无主机提示）。

## 8. 已知限制

1. 纯 RDP 会话必须放 Mesa dll；放好后自动走 llvmpipe。
2. 数据流需要 NTFS；FAT32/exFAT 保存会报错。
3. 最新数据在正常退出后才写进 exe 字节；运行中直接压缩只带上次退出时的数据。
4. 同一 IP 不同端口的凭据共享 `TERMSRV/<主机>`，是 Windows 的限制。
5. 没有真实 RDP 目标机，端到端只验证到拉起 mstsc。
6. 单实例：第二个实例会提示并退出。
7. 历史导入只覆盖 mstsc 的 MRU / Servers 记录；导入的主机没有备注名、没有密码。
8. 最新版检查需要访问 github.com；GitHub 的 REST API 限流 60 次/小时，所以主路用 `releases/latest` 跳转。
9. 网络盘卷标由后台线程补：启动瞬间只显示盘符，掉线的网络盘要等 SMB 超时（几十秒）才有卷标，界面不受影响。
10. 盘符存在性后台预探，刚启动那一瞬可能乐观地写进 `.rdp`（mstsc 会忽略）。
11. 导出文件 `.rdplcfg` 用和 exe 存储同一把密钥（固定口令派生），任何一份本软件都能解开：
    定位是「换机可读 + 不是明文」，丢了也不至于被人直接打开，但不是「有密码才解不开」。
12. 原生文件选择框是模态阻塞调用，在断开的 RDP 会话里没法用注入鼠标点（截图 / 自测走
    `RDP_LAUNCHER_EXPORT_TO` / `RDP_LAUNCHER_IMPORT_FROM` 跳过）。
